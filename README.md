# FERM Motion

WordPress motion effects and photo sliders for FERM, adapted from DURF Motion 1.11.12 by Anelli Studio.

Use the FERM Motion menu to configure reveals, parallax, colour flow and the adaptive header. Apply the documented `dm-*` classes to WPBakery elements. Create photo sliders under FERM Motion and insert their `[ferm_slider id="…"]` shortcode. Use WPBakery for page layout and sticky columns.

Install the ZIP through Plugins → Add New → Upload Plugin. Git Updater reads plugin versions from the main branch. For the private repository, grant the site's GitHub token read access to this repository.
